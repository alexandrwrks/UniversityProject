# Повторная проверка лабораторных №1 и №2

## Исправленные расхождения макетов

В предыдущей реализации AddressControl содержал шесть вертикальных строк. Это не соответствовало изображениям на страницах 8–9 ТЗ второй лабораторной. Теперь:

- Заголовок Delivery Address входит в сам AddressControl.
- Post Index расположен отдельно в коротком поле.
- Country и City находятся в одной строке.
- Street занимает всю доступную ширину после подписи.
- Building и Apartment находятся в одной строке в коротких полях.
- Id в Customers и Items показан в коротком поле только для чтения.
- Заголовки выделены полужирным; список и кнопки расположены слева, редактор справа.
- Устранены переносы подписей Full Name и Category при минимальном размере окна.

Расположение AddressControl вынесено в Designer.cs. Объект Address, проверка ввода и отдельные последовательности Id для товаров и покупателей сохранены.

## Проверенные обязательные требования

| Требования | Результат |
| --- | --- |
| Закрытые поля Item и Customer, readonly Id, инициализация через свойства | Выполнено |
| Название/ФИО до 200, описание до 1000, стоимость 0–100000 | Выполнено; NaN и бесконечность отклоняются |
| Выбор, добавление, редактирование, удаление, подсветка неверного ввода | Проверено |
| Category: не менее 7 значений, открытое автосвойство, ComboBox через Enum.GetValues | Выполнено |
| Address: шестизначный индекс, длины строк 50/50/100/10/10, два конструктора | Выполнено |
| AddressControl: отображение адреса, редактирование, подсветка, пояснения ошибок | Проверено |
| Getter Address возвращает актуальные корректные значения | Проверено, включая ошибку в другом поле |
| Store и передача его List<Item>/List<Customer> во вкладки без копирования | Проверено |
| Раздельные Id с 1 | Сохранено по пожеланию пользователя; удаление не перенумеровывает записи |

Название существующего проекта UniversityProject и расположение репозитория сохранены. Команды PDF по веткам, коммитам и синхронизации не выполнялись. Дополнительные задания на генерацию случайных данных и сохранение в файл не реализованы. Пустые строки допустимы, поскольку ТЗ задаёт максимальные длины; индекс пустого адреса — минимально допустимый 100000.

## Проверка

Сборка приложения и проверочного проекта проходит без ошибок и предупреждений. Проверочная программа: PASS, 66 проверок.

Геометрия адреса проверяется при размерах 820×490 и 1200×800: совместные строки Country/City и Building/Apartment, порядок строк, широкое поле Street, короткие индекс и дом, отсутствие обрезания полей. Изображения обеих вкладок визуально просмотрены и сопоставлены с макетами PDF. Результаты отрисовки находятся в tmp/review; большие Id на этих изображениях вызваны созданием объектов в проверках.

Ручное открытие конструктора Visual Studio и другие масштабы Windows не проверялись. Новых функциональных несоответствий перечисленным обязательным требованиям не обнаружено.
