# Лабораторная №6 — стандартные интерфейсы

Ветка `Tasks/6_standard_interfaces` создана от develop после слияния №5. Изменения интерфейса пользователя не требуются.

- ICloneable реализован в Item, Address и Cart. Item.Clone создаёт новый товар с новым Id и копией значений. Address.Clone создаёт независимый адрес. Cart.Clone создаёт отдельную коллекцию тех же агрегируемых товаров, сохраняя повторы и порядок.
- IEquatable<T> и Equals(object) реализованы в Item, Address, Order. Товар и заказ равны по уникальному неизменяемому Id; обычные и приоритетные заказы используют одну последовательность. Адрес равен по всем шести составляющим, строки сравниваются с учётом регистра. GetHashCode согласован с Equals. Изменяемый адрес не следует менять, пока он служит ключом словаря или элементом HashSet.
- IComparable<T> реализован в Item по Cost, PointsDiscount по Points, PercentDiscount по Percent. Любой существующий объект больше null. Разные объекты с одинаковой ценой/баллами/процентом сравниваются как 0, даже если Equals возвращает false: сортировка и равенство решают разные задачи.

При создании заказа теперь используется Address.Clone вместо ручного перечисления составляющих адреса.

## Ревью и проверка

Проверены независимость копий и коллекций, сохранение ссылок и повторов в копии корзины, новый Id товара, все составляющие адреса, null, посторонний тип, симметричность сравнения, стандартная List.Sort, стабильность хеша сущностей после редактирования и одинаковый хеш равных адресов. Ревью проверило согласованность типизированного и объектного Equals.
