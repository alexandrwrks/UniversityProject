# Лабораторная №7 — делегаты

Ветка `Tasks/7_delegates` создана от develop после №6. Реализована обязательная часть без LINQ в алгоритмах DataTools.

## Алгоритмы и интерфейс

DataTools.Filter принимает List<Item> и Func<Item, bool>, возвращая новый список ссылок без изменения исходного. Открытые критерии CostAbove5000 и IsElectronics покрывают первые учебные примеры. Поисковая строка Items передаёт собственный критерий подстроки имени. Регистр не учитывается, используется текущая культура.

DataTools.Sort получает список и внешний Func<Item, Item, bool>, означающий «первый товар должен стоять раньше второго». Сортировка вставками создаёт новый список и сохраняет порядок равных элементов. Есть открытые критерии по имени, цене вверх и цене вниз. В итоговой реализации используются встроенные Func вместо собственных типов делегатов.

На Items поиск расположен над каталогом, Order By — под ним. Начальный порядок по имени. Сортировка применяется после фильтрации; смена одного параметра сохраняет другой и выбранный объект, пока он присутствует среди результатов. Редактирование выполняется по ссылке на SelectedItem, а не по индексу в Store. При изменении имени/цены список сразу упорядочивается заново. Если имя перестаёт удовлетворять поиску, запись скрывается и редактор отключается. Add очищает поиск и выбирает новый товар.

## Ревью и окончательная проверка

После ревью удаление выбирает соседа из отображаемого списка, а не из исходного каталога. Обновление списка при вводе сохраняет текст и положение ввода в редакторе. Исходные проверки выбора адаптированы к обязательной сортировке по имени: объект выбирается по ссылке.

Проверены строгое условие >5000, категория, внешние критерии, все сортировки, стабильность, отсутствие изменений исходного списка, пустой результат, null, поиск без учёта регистра, совместная работа поиска и сортировки, редактирование и удаление отфильтрованного товара, переименование за пределы фильтра и добавление во время поиска. Итог: **249 проверок**, сборка без предупреждений и ошибок. Проверен макет при маленьком размере окна.
